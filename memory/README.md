# Memoria — estructura mínima de una bóveda nueva

Cuando la Fase 2 crea una bóveda nueva (nadie la adoptó de una instalación previa), la Fase 3 la deja con esta estructura mínima antes de dar la pieza por instalada:

- **`VAULT-INDEX.md`** en la raíz — nota índice corta: quién es la persona (nombre de la Fase 2), qué es esta bóveda, y el mapa de carpetas tal como exista en ese momento (al principio, solo `Notas Diarias/`).
- **`Notas Diarias/`** — carpeta vacía donde el asistente irá registrando sesiones, una nota por día.

Nada más al crearla. El resto de la estructura (carpetas de proyecto, notas de referencia) la construye el propio asistente con el tiempo, a medida que la conversación lo pida — no se le impone una plantilla grande el primer día.
